## 🎓 Lessons Learned

### 1. Modern Sites Need Modern Tools
- HubSpot is built with React
- CTAs load dynamically
- Chat widgets load after page load
- Analytics scripts are asynchronous

**Without Selenium:** You're analyzing a skeleton
**With Selenium:** You're analyzing the real site

### 2. False Negatives Are Expensive
Missing features (false negatives) makes you look incompetent:
- "You have no chat" (they do)
- "You have no tracking" (they do)
- "Your CTAs are weak" (they have 9!)

**Selenium eliminates false negatives.**

### 3. The 68 → 92 Jump Is Standard
For modern JavaScript sites:
- Basic scraper: 60-70 scores
- Selenium scraper: 85-95 scores
- **20-30 point difference is typical**
